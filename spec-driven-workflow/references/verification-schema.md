# Verification record

Evaluate the current acceptance criteria with evidence from the implemented result. Record the check performed, observed result, and affected target. Do not claim checks that were not run.

For an auditable Spec, record each criterion as `PASS`, `FAIL`, or `BLOCKED`, with concise evidence. A failed criterion calls for a fix or a change to the plan or contract; use `BLOCKED` for a check prevented by an external dependency. Retain relevant logs or screenshots only when they add value.

Conclude `DONE` only when every applicable criterion passes with current evidence and no material blocker remains. After a change, rerun checks whose evidence may be stale. Record remaining failures or blockers precisely so work can resume.
